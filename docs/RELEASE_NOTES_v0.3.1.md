# CODEX ACCESS ENGINE v0.3.1 — local development

Independent Windows named-pipe broker, OS-derived executable enrollment, centralized
policy/vault/provider routing, public IPC SDK, lifecycle CLI and two external clients.
Existing in-process SDK, Control Center and seven providers are preserved.

Builds are unsigned. The broker runs under the current account; it is not a
separate-identity Windows service or a hostile same-account security boundary.
See BROKER_VALIDATION.md and INTEGRATION_RESULTS.md for executed results.
No GitHub publication is authorized by the current engineering task.
